# NATIX Network

> NATIX Network is a decentralized physical infrastructure (DePIN) network building the world's largest on-street camera network to power Physical AI, autonomous driving, and real-time mapping. Drivers collect, validate, and monetize privacy-preserved dashcam footage via the Drive& app and VX360 smart-camera device, earning $NATIX token rewards.

Source: https://docs.natix.network/llms.txt (searched verbatim, 2026-07-20). Docs are a GitBook whitepaper; each page has a `.md` version and a `llms-full.txt` export. NATIX publishes no public REST/GraphQL developer API.
